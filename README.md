# Matthew Koegler — Business Operations & Systems

Portfolio covering business operations, payments, reporting, billing workflows, and systems implementation.

## Updating the site

Edit `content.json` for project and experience content. Edit `site.css` for styling or `build.py` for layout. Run `python3 build.py`, then commit the updated source and `docs/` output. Python uses only its standard library.

GitHub Pages publishes from the `main` branch and `/docs` directory. No package install or runtime server is required.

## Work samples

The financial dashboard, memo, SOP, and downloadable sample workbook use illustrative data. All sample processors, partners, merchants, and financial figures are fictional. These figures are not actual employer results or personal achievement metrics. The operational revenue-share workbook is excluded.
